# 🎵 Spotify App Clone

A static **Spotify UI clone** built using HTML and CSS, mimicking the look and feel of the official Spotify web player. This project is focused on **frontend design** and can be a foundation for adding interactivity using JavaScript or integrating a music API in the future.

---

## 🚀 Features

- 🎧 Home screen layout with navigation sidebar
- 📁 Playlist section
- 🎼 Now playing footer with control icons
- 🎨 Clean and responsive layout styled with custom CSS
- 🖼️ Spotify-like icons and assets for authenticity
